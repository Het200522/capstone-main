## 🎨 DESIGN SPECIFICATIONS

### Color System
```
Primary Blue:      #0066CC (Headers, buttons, borders)
Success Green:     #00A86B (Positive indicators)
Background:        #FAFAFA (Light, clean)
Card White:        #FFFFFF (Content containers)
Text Dark:         #1A1A1A (Readable text)
Warning Yellow:    #FFB800 (Disclaimers)
Error Red:         #FF6B6B (Attention indicators)
```

### Typography System
```
Font: Segoe UI (Professional, healthcare-friendly)

Sizes:
  - Page Titles: 3rem (48px)
  - Section Headers: 1.8rem (28px)
  - Card Titles: 1.2rem (18px)
  - Body Text: 1rem (16px)
  - Small Text: 0.9rem (14px)

Weights:
  - Regular: 400 (Body)
  - Semi-Bold: 600 (Labels, headers)
  - Bold: 700 (Titles)
```

### Component System
```
Medical Cards:      Left border accent, shadow
Result Cards:       Gradient background, color-coded
Info Boxes:         Light background, left border
Disclaimer Boxes:   Warning styling, clear text
Buttons:            Gradient, hover effects
Forms:              2-column desktop, 1-column mobile
```
