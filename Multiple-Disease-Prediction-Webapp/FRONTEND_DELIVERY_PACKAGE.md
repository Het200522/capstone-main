```

Background: #FAFAFA (Off-White)         - Clean, calming

Warning:    #FFB800 (Yellow)            - Caution, notice
Error:      #FF6B6B (Muted Red)         - Attention, urgent
```

### Typography System

```
Font Stack: 'Segoe UI', Tahoma, Geneva, Verdana
           (Professional, modern, healthcare-appropriate)

Size Hierarchy:
  Page Titles:     3rem (48px)  - Hero impact
  Section Headers: 1.8rem (28px) - Clear organization
  Card Titles:     1.2rem (18px) - Visual hierarchy
  Body Text:       1rem (16px)   - Standard readability
  Small Text:      0.9rem (14px) - Secondary info

Weight System:
  Regular:     400 - Body text
  Semi-Bold:   600 - Labels, headers
  Bold:        700 - Page titles
```

### Spacing System

```
Large:    2rem (32px)   - Major section spacing
Medium:   1.5rem (24px) - Component spacing
Normal:   1rem (16px)   - Standard padding
Small:    0.5rem (8px)  - Micro spacing

Border Radius:
  Cards:   12px - Soft, modern
  Buttons: 8px  - Friendly, approachable
  Inputs:  6px  - Consistent
```
